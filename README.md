> 상인 화면은 상단 **"가격 등록"** → PIN `1234`

포항 죽도시장의 **가격 정보 비대칭 문제**를 다루는 모바일 웹 프로토타입입니다.
손님은 여러 가게 시세를 한눈에 비교하고, 상인은 자기 가게 가격을 직접 등록하며,
등록된 가격이 **모든 접속자에게 실시간으로 공유**됩니다.


## 주요 기능

### 손님
- **가격 비교** — 품목별 전 매장 시세를 낮은 가격순/최신순 등으로 정렬
- **목표가 알리미** — "이 가격 이하면 알려줘" 기준을 걸어두면 카드·홈에서 즉시 표시
- **매장 비교함** — 최대 3곳을 담아 표로 나란히 비교
- **장보기 최적 플랜** — 찜한 품목마다 최저가 매장을 찾아 가게별로 묶고 총액 산출
- **동선 안내** — 구역 번호 기반 방문 순서 + 완주 체크리스트
- **영수증 OCR 인증** — 브라우저 내 Tesseract.js로 영수증의 가게명·금액을 대조해
  실제 구매자만 후기를 남길 수 있게 함 (로딩 실패 시 사진 첨부 방식으로 자동 대체)

### 상인
- **PIN 인증** (데모용 `1234`) 후 본인 가게의 상품표 직접 관리
- **세부 가격 등록** — 단순 무게당 가격 외에 `총 개수 · 한 개당 무게 · 가격` 구조 지원
- **실시간 입력 힌트** — 가격 입력 중 다른 매장 시세와 비교해 즉시 피드백
- **성과 요약** — 표를 열자마자 내 가게의 현재 위치(최저가 여부 등)를 요약

### 외국인 관광객
- 4개 언어 전환 · 언어에 맞춘 통화 환산(USD/JPY/CNY, 고정 데모 환율)
- **문구집 음성 재생** — 브라우저 내장 음성합성으로 한국어 문장을 들려줌

### 시장 전체
- **시장 라이브** — 실시간 소식 · 오늘의 특가 · 신뢰 랭킹

## 아키텍처: 자기복제형 공유 문서

이 프로토타입의 핵심 설계입니다. **서버 없이 여러 사람이 같은 데이터를 보게** 만드는 구조입니다.

```
┌─ HTML 문서 ─────────────────────────────────┐
│  <script id="app-state">   ← 지금까지의 공유 상태(JSON)  │
│  <script id="doc-shell">   ← 자기 자신의 원본 틀(전체 복사본) │
│  <script> 앱 로직 </script>                             │
└────────────────────────────────────────────┘
```

동작 순서:

1. 부팅 시 `#app-state`의 JSON을 읽어 `priceData` 등에 복원
2. 누군가 가격을 등록하면 → `#doc-shell`의 원본 틀을 꺼내
3. 자리표시자 두 곳(`__APP_STATE_JSON__`, `__DOC_SHELL_SELF__`)에 **새 상태를 주입**해
   완성된 새 HTML 문서를 생성
4. `window.claude.use('artifact').publish(html)`로 게시 → 모든 접속자가 새 버전을 봄

이 구조 때문에 파일 안에 자기 자신이 한 번 더 들어있고, 그래서 실제 소스 8,200줄이
13,226줄로 보입니다.

### 이 구조에서 생겼던 함정들

- **스크립트 조기 종료** — 소스 안에 `</script>` 글자가 주석·문자열 어디든 그대로 있으면
  브라우저가 그 자리에서 스크립트가 끝난 걸로 착각합니다. 그래서 해당 문자열을
  `'<' + '/' + 'script'`처럼 조각내어 이어붙입니다.
- **자기 자신을 치환하는 사고** — 자리표시자 상수를 한 덩어리로 쓰면, 그 코드가
  `#doc-shell` 안에 복사될 때 치환 로직이 자기 코드까지 바꿔버립니다. 역시 조각내어 회피.
- **`String.replace`의 `$` 해석** — 치환 문자열의 `$&`, `$1` 등이 특수 패턴으로 해석되는데
  이 문서엔 `${...}` 템플릿 리터럴이 아주 많아 실제로 위험합니다. `split().join()`으로 대체.
- **동시 저장 경쟁 상태** — 같은 항목에 게시가 겹치면 나중 응답이 먼저 것을 덮어씁니다.
  `pendingPublishKeys` Set으로 같은 키의 중복 게시를 차단.
- **저장 후 화면 이탈** — 게시에 성공하면 페이지가 새 버전으로 새로고침되므로, 그 전에
  보던 화면을 `sessionStorage`에 적어두고 부팅 시 복원(`restoreResumeStateIfAny`).

## 배포 환경별 동작 차이 ⚠️

이 앱은 **Claude Artifact 환경을 전제**로 만들어졌습니다. 배포 위치에 따라 기능이 달라집니다.

| 기능 | Claude Artifact | 정적 호스팅(Vercel 등) | 파일 직접 열기 |
|---|---|---|---|
| 가격·후기 **실시간 공유** | ✅ 동작 | ❌ 내 브라우저에만 저장 | ❌ 내 브라우저에만 저장 |
| 영수증 **OCR 인증** | ⚠️ CSP로 CDN 차단 → 사진 첨부 방식으로 대체 | ✅ 동작 | ✅ 동작 |
| 지도 임베드 · 품목 사진 | ⚠️ CSP로 차단될 수 있음 | ✅ 동작 | ✅ 동작 |
| `localStorage` 개인 설정 | ✅ | ✅ | ❌ 차단됨 |

`window.claude`가 없는 환경에서는 `publishSharedState()`가 `'local-only'`를 반환하고
다음 배너를 띄운 뒤, 변경 사항을 로컬 화면에만 반영합니다.

> 지금은 다른 사람과 공유되는 상태가 아니에요(이 화면에서만 보여요).

**앱이 깨지지는 않지만, 여러 사람이 같은 데이터를 보는 핵심 기능은 동작하지 않습니다.**
(Artifact로 열었지만 편집 권한이 없는 경우에는 대신 "지금은 보기 전용 링크예요" 배너가 뜹니다.)

## 알려진 한계

- 시드 데이터의 가격·가게 이름은 **실제 시세가 아닌 데모용 가상 값**입니다.
- 환율은 2026-08 기준 **고정값**이며 실시간 API 연동이 아닙니다.
- 동선 안내는 구역 번호 순 정렬이지 **정확한 최단 경로가 아닙니다**.
- 상인 PIN은 데모용 `1234` 고정이며, 실제로는 서버 검증이 필요합니다.
- 영수증 OCR은 사진 합성까지 막지는 못합니다.
