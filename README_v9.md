## 주요 기능

### 손님
- **가격 비교** — 품목별 전 매장 시세를 낮은 가격순·최신순 등으로 정렬
- **필터** — 가격대 · 품목 종류(생물/건어물/손질 정도) · 원산지 · 택배 가능 여부
- **오타 보정 검색** — 편집거리(Levenshtein) 기반으로 비슷한 이름도 찾아줌
- **찜하기** — 품목(가게+품목 단위)과 가게를 각각 북마크
- **후기·투표** — "가격 맞았어요 / 달라요" 투표와 텍스트 후기
- **다국어** — 4개 언어 전환 + 달러 환산 표시

### 상인
- **PIN 인증** (데모용 `1234`)으로 회원가입 없이 진입
- **상품 표 관리** — 상품 추가/수정/삭제를 표에서 일괄 처리 후 한 번에 저장
- **두 가지 가격 방식**
  - 단순 무게당 가격 — `20,000원 / kg`
  - **세부 가격** — `총 개수(또는 총 무게) · 한 개당 무게 · 가격`
- **목록에 없는 품목 등록** — 새 품목을 카테고리·단위와 함께 직접 추가

### 신뢰 장치
- 상인 측 — 오픈채팅방에 매일 올라오는 4자리 PIN
- 손님 측 — **영수증 인증을 거친 카드에서만 후기 작성 가능**
  (v9에서는 백엔드가 없어 버튼 클릭으로 시뮬레이션. v19부터 실제 OCR로 대체됨)

## 데이터 흐름

백엔드가 없어 두 개의 저장 계층으로 동작합니다.

```
[상인 상품 화면]  저장 버튼
       │
       ├─→ localStorage  "vp_products_<가게명>"   ← 가게별 영구 저장소
       │
       └─→ priceData (메모리)                     ← 손님 화면이 읽는 데이터
                │
       페이지 로드 시 ↑ 다시 주입
```

핵심은 **페이지가 열릴 때마다 `localStorage`의 모든 가게 데이터를 `priceData`에 다시
반영하는 것**입니다. 이 과정이 없으면 저장은 되지만 새로고침 시 예시 데이터로 되돌아갑니다.

```js
Object.keys(localStorage).forEach(key => {
  if (!key.startsWith('vp_products_')) return;
  const storeName = key.slice('vp_products_'.length);
  const saved = JSON.parse(localStorage.getItem(key));
  if (saved && saved.products && saved.products.length) {
    vpSyncToPriceData(storeName, saved.products, saved.delivery);
  }
});
```

`vpSyncToPriceData()`는 그 가게의 기존 등록 내역을 **전부 지우고 저장분으로 통째 교체**합니다.
그래서 상품 삭제도 손님 화면까지 그대로 이어집니다.

## 세부 가격 표시 규칙

상인이 "세부 가격"으로 등록한 상품은 손님 화면에서 다음 순서로 표시됩니다.

```
[가게명] · [품목명] [총 개수/총 무게] [한 개당 무게] [가격]

예)  바다마트 · 전복 6개 170g 50,000원
     청호상회 · 오징어 20kg 400g 15,000원
```

매장 상세 화면에서는 가게명이 이미 상단에 있어 품목명부터 표시됩니다 (`전복 6개 170g 50,000원`).
세부 가격이 아닌 일반 상품은 기존 형식(`가게명 · 품목명 단위`)을 유지합니다.

## 알려진 한계

- 가격·가게 이름은 **실제 시세가 아닌 데모용 가상 값**입니다.
- **데이터가 기기별로 분리됩니다.** `localStorage` 기반이라 A가 등록한 가격을 B는 볼 수
  없습니다. 발표·시연용으로는 충분하지만 실서비스에는 백엔드가 필요합니다.
  → 이 한계를 해결한 것이 [v35의 자기복제형 공유 구조](README.md#아키텍처-자기복제형-공유-문서)입니다.
- 환율은 조회 시점 고정값이며 실시간 API 연동이 아닙니다.
- 상인 PIN은 데모용 `1234` 고정이며, 실제로는 서버 검증이 필요합니다.
- 영수증 인증은 버튼 클릭 시뮬레이션입니다.
